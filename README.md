# AI Story Production · AI 图文故事制作

这是当前实际使用的完整 Skill，公开全部有效制作规则，并附带 GPT 网页版规范。

## 内容

- 故事因果、整期分镜、逐张提示词和审核流程。
- 角色四视图：正面面部特写、正面全身、标准侧面全身、背面全身。
- 手机纪实画风：默认阴天，夜晚近乎无灯，中性偏冷、低照度；不自动添加潮湿效果。
- 六类影视术语白名单、换场规则和第一人称手部规则。
- 正式参考、LOCKED 版本、生成授权、连续性检查和交付。
- GPT 网页版使用规范与会话交接。

## 使用

### Codex

把本目录保存为技能目录下的 `ai-story-production` 文件夹，保留 `SKILL.md` 和 `agents/`。
在支持技能的环境中明确调用：

```text
使用 $ai-story-production，把这个故事整理成分镜和逐张提示词。
我自己生成图片。
```

### GPT 网页版

把 `web/AI图文故事制作规范.md` 上传到当前会话，要求按它执行，再上传当前故事和必要参考图。
新会话需要重新提供规范、最新交接和正式参考。上传文件不代表模型已经读取，实际行为以当前会话能力为准。

```text
读取我上传的 AI 图文故事制作规范，按它规划故事。
先完成故事逻辑和分镜，暂时只交付提示词。
```

## 默认规则

这套规则公开的是实际使用版本，包含具体画风偏好；需要其他天气、光线或风格时，可明确指定。
角色参考图使用均匀中性偏冷光线以便识别；剧情画面使用阴天或夜间弱光。
只有明确要求生成或修改图片时才执行图片操作。

# 完整示例：最后一场放映

一则独立原创的 6 张第一人称图文故事。可以直接按顺序制作，也可以替换设定后重新规划。

这是文字制作示例，尚未生成图片。文中所有 LOCKED 文件名都是未来通过审核后的建议名称，仓库没有提供这些图片。

## 一句话故事

旧电影院拆除前，一位已故放映员的成年孩子回来取父亲的录音机，重听父亲预先录下的闭场广播，最终把录音和记忆一起带回家。

## 从这里开始

1. 在 Codex 中调用本 Skill，或在 GPT 网页版上传规范。
2. 上传本示例，确认使用下面的故事与分镜；需要改设定时先改故事和路线。
3. 按“必要资产”准备录音机参考，经审核通过后命名 RECORDER-LOCKED。
4. 用 P01 提示词制作第一张，确认风格后命名 P01-LOCKED。
5. 逐张制作 P02–P06。每张只上传该页列出的、确实已通过的参考图。
6. 把该页文案放在图片外，最后按页码拼成图文故事。

## 故事与空间

主角是成年人的第一人称拍摄者，不露脸；父亲是已故的退休放映员，只通过文案与录音出现。
主角受母亲委托，在拆除前取回父亲留在放映室的录音机。进入大楼后找到纸条，按播放键听到父亲事先录下的闭场广播，听完关机并带走。

“本场放映结束”和“别一直留在这里”既是闭场广播，也让主角愿意离开这栋承载回忆的建筑。
没有电力恢复、自动播放、鬼魂、隐藏人物或悬而未决的支线。录音机有可用电池，只有按键后才播放。

固定路线：

前院 → 售票大厅 → 右侧服务楼梯 → 二楼短走廊 → 放映室靠窗桌区 → 相邻休息间 → 后楼梯下到一楼后门通道 → 后巷转角。

P04 到 P05 的下楼过程通过文案和空间说明承接，不另加一张功能重复的过渡图。
P01 到 P02 的进楼与上楼过程也由文案和路线承接，省去两张重复通行画面。第 3 张就出现录音机和纸条。
全过程约九分钟。本故事明确设定为阴天下午、建筑与地面干燥、停业断电，室内只使用窗与门透入的光。这是当前故事的现场条件，不是所有故事的默认天气、色调或亮度。

## 必要资产

### 主角

不需要完整四视图：全程不露脸。只固定成年人的左手、炭灰色外套袖口、无标识黑色布包。
只在 P04 操作按键与 P06 托包时露左手，右手不入画；第一人称视角不额外要求展示手机或拍照动作。
若改成露脸主角，先制作正面面部特写、正面全身、标准侧面全身、背面全身的单张四栏参考。

### 录音机

它在 P03、P04、P06 出现，必须先锁定外观。资产提示词：

```text
一台蓝灰色便携磁带录音机，约一本小书大小，矩形塑料机身，左侧黑色圆形扬声器，右侧透明磁带窗内装白色磁带，可见两个黑色卷轴，顶部一排实体按钮，其中白色播放键与红色停止键清楚可辨，无电线、无发光屏幕、无文字标识。单一物品，正面略带顶部的视角，浅灰纯色背景，均匀自然光，普通手机照片质感，真实材料与轻微使用痕迹，边缘完整，不裁切，不添加装饰、手或其他物品。
```

参考图通过后保存为 RECORDER-LOCKED。首次剧情中装有可用电池；P03 关闭，P04 按键播放，P05 已停止并装包，P06 关闭且播放键回弹。
这是物品资产，使用便于识别的均匀照明；剧情照明按各页实际现场执行。

### 场景

各页进入不同子空间，没有跨页反复拍同一机位，不额外生成全楼场景资产。
路线与材质由本稿锁定；P01 通过后仅作为画风依据，不能把每页背景都复制成前院。

## 逐页文案与可复制提示词

文案在发布时配到图片外；提示词只描述画面，不要求生成器在图中写故事或表现声音。六类镜头参数保留在分镜中，可复制提示词只写本页需要的主体、空间、动作与拍摄范围，不照抄整套审核规则。

### P01｜回来

发布文案：父亲去世后，我一直没再来过这家电影院。明天它就要拆了，母亲让我取回他留下的录音机。

- 时间：15:00，持续阴天。
- 本张信息：交代目的与入口；录音机尚未出现。
- 前后承接：进入大厅，走右侧服务门后的楼梯，上二楼左转到放映室门前；这段通行在下一页文案承接。
- 主角状态：成年、炭灰色外套；尚未携带录音机。

```text
阴天下午，停业的旧电影院前院，天空铅灰，干燥水泥地面。拍摄者站在入口正前方，正望向两扇已打开的深绿色木门。门内暗，门外只有阴天微弱漫射光。外墙灰色，左右各一扇封闭售票窗，空白招牌没有文字。
全景 LS，完整展示影院入口与左右售票窗。
3:4 竖图。第一人称视角，普通手机主摄成像，像亲眼看见的生活现场。
```

本张上传参考：无需剧情参考图。先定稿本张，用户通过后才命名 P01-LOCKED。

### P02｜门还开着

发布文案：穿过大厅，上了二楼。管理员已经搬空设备，放映室里只剩父亲的旧木桌。

- 时间：15:03，持续阴天。
- 本张信息：确认设备搬空和桌子存在；此页不能清楚展示录音机。
- 前后承接：由半开的门进入，走到放映室靠窗的桌边。
- 主角状态：成年、炭灰色外套；尚未携带录音机。

```text
阴天下午，旧电影院二楼短走廊，站在楼梯出口前，略向下观察左侧一扇半开的灰色放映室门和门槛。门只占画面左侧，右侧留下昏暗空墙和干燥地面。走廊尽头小窗提供微弱冷灰光；门内仅露出一张旧木桌的边缘和空机座，桌面细节被门遮挡。
全景 LS，门在画面左侧，右侧保留空走廊。
3:4 竖图。第一人称视角，普通手机主摄成像，像亲眼看见的生活现场。
```

本张上传参考：已通过的 P01-LOCKED：只延续画风和建筑材料；二楼空间由本稿定义。

### P03｜留给我的

发布文案：录音机下面压着父亲的纸条：“带走前，再听一次。”

- 时间：15:04，持续阴天。
- 本张信息：首次揭示录音机和纸条；纸条文字仅放在页外文案。
- 前后承接：拿起录音机与纸条，到相邻休息间听录音。
- 主角状态：成年、炭灰色外套；尚未携带录音机。

```text
阴天下午，放映室靠窗的旧木桌旁，向下观察桌上的一台蓝灰色便携磁带录音机。机身左侧黑色圆形扬声器，右侧透明磁带窗内有白色磁带和两个黑色卷轴，顶部有白色播放键与红色停止键，没有电线。录音机放在三分交叉点，下方露出一角折叠米白纸条，但纸面没有可读文字。前景桌面有干燥灰尘，背景空机座模糊；右侧窗提供现场漫射光。
```

### P04｜熟悉的声音

发布文案：我按下播放键。父亲的声音响了起来：“本场放映结束，请带好随身物品。”

- 时间：15:05，持续阴天。
- 本张信息：按键触发父亲预先录下的闭场广播；不出现父亲实体或声波特效。
- 前后承接：听完录音、按停止键、收进布包，沿后楼梯下楼到后门。
- 主角状态：成年、炭灰色外套；录音机播放中，纸条已放入布包。


本张上传参考：P01-LOCKED：画风；RECORDER-LOCKED：道具；已通过的 P03-LOCKED：纸条和录音机当前状态。

### P05｜带好随身物品

- 主角状态：成年、炭灰色外套；录音机已停止，录音机与纸条均在布包内。

发布文案：我带走了录音机，也带走了最后一次闭场广播。明天这里会消失，但父亲的声音不会。

- 时间：15:09，持续阴天。
- 本张信息：物品成功带离，父亲的声音得以保存，完整收束。
- 前后承接：故事结束；不凭空增加人物、超自然事件或新支线。
- 主角状态：成年、炭灰色外套；录音机已停止，录音机与纸条均在布包内。

## 每张做完后怎么审核

先对照该页提示词核对空间与动作，再检查画风和上一页连续性。用户通过后才改成 LOCKED；未通过图不得继续作为参考。
按现场光线呈现人物、道具和环境，不单独为手部或道具补出无来源的亮光。录音的内容靠发布文案表达，不生成父亲实体、声波或凭空发亮的设备。

常见返工示例：

```text
P04 返工。
CHANGE：把按键手改为左手，左拇指只按白色播放键。
PRESERVE：录音机的蓝灰色外壳、左侧黑扬声器、右侧白磁带、红停止键；
矮桌、黑布包、米白纸条与小窗位置保持。
通过条件：单只左手动作合理，道具与正式参考一致，手、机器和背景共享小窗的现场光线。
只给修改提示词。
```

最终确认：

- 六张分别进入六个可辨认的子空间，路线能走通。
- 只有 P04、P06 露手，均为左手；脸、右手与父亲实体均不出现。
- 录音机只有一台，不变色、不换按钮；播放与停止状态按剧情发生。
- 从开始到结束符合本故事已确认的阴天、干燥地面与停业断电条件；光线来自门窗，不额外补亮手部或道具。
- 图中文字不承担关键信息；纸条与广播内容均在发布文案中说明。
- 六段文案和六张图片一一对应，取物、播放、离开、带回的故事完整成立。

## 换成自己的故事

保留流程与提示词结构，先替换主角目标、行动理由、物品与结尾，再重写空间路线和整期分镜。
不要只换名字就沿用全部画面。新增露脸角色时补四视图；新增反复出现的物品时补资产；天气、光线或风格要改时明确写出。
